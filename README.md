# React Pryt

Proyecto frontend hecho con React (Vite) + React Router.

## Iniciar el proyecto

```bash
npm install
npm run dev
```

## Iniciar sesión

El registro de usuarios aún está pendiente, por ahora solo existe **un usuario registrado**. Para entrar al sistema debes iniciar sesión con estas credenciales:

| Campo            | Valor            |
| ---------------- | ---------------- |
| Correo           | `master@mail.com` |
| Contraseña       | `3445`            |

Si escribes correo o contraseña incorrectos, no se podrá ingresar y se mostrará un mensaje de error.
